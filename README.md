## 📖 About The Project

**Thrift by Musk** is a curated vintage clothing store focusing on sustainability, quality, and style. As the **Technical Lead**, I engineered this platform to deliver a seamless shopping experience that mirrors the brand's "Luxe & Clean" aesthetic.

The application is optimized for speed, featuring dynamic product galleries, a "Saved Items" wishlist system, and a zero-layout-shift architecture for mobile devices.

### 🌟 Key Features
* **🛍️ Dynamic Product Catalog:** Filterable categories (Tops, Shirts, Dresses) with high-res image optimization.
* **❤️ Saved Items (Wishlist):** LocalStorage-based wishlist functionality allowing users to curate their favorite finds.
* **📱 Mobile-First Design:** Fully responsive UI built with Tailwind CSS, ensuring 100% design fidelity across devices.
* **🚀 High Performance:** Optimized critical rendering path to achieve a **98/100 Lighthouse Performance Score**.
* **✨ Interactive UI:** Smooth transitions, "Fresh Drop" countdowns, and an immersive "Unboxing" story section.

## 🚀 Getting Started locally

Follow these steps to set up the project locally on your machine.

### Prerequisites
* Node.js (v18 or higher)
* npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/NavneetSharmaProgrammer/thrift-by-musk.git](https://github.com/NavneetSharmaProgrammer/thrift-by-musk.git)
    cd thrift-by-musk
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Configure Environment Variables**
    Create a `.env.local` file in the root directory and add your keys (if using AI features):
    ```env
    VITE_GEMINI_API_KEY=your_api_key_here
    ```

4.  **Run the development server**
    ```bash
    npm run dev
    ```
